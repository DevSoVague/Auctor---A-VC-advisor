Method

How the analysis is built

Eight agents. Code decides what runs next; models read, reason and write.

No future data

Every record is dated and anything after the as-of cutoff is invisible to the agents.

Every claim cited and checked

A citation checker verifies each source supports its claim; unsupported claims are removed before the memo.

Every claim traced to its agent

Each claim carries the agent that made it, so any statement can be followed back.

The memo agent never searches

It reads only the other agents' checked output, so it cannot bring in outside sources.
